# Task Tracker

A simple command-line task management application built with Dart. It lets users add, list, edit, delete, prioritize, search, and monitor tasks from a terminal-based menu.

## Overview

This project was designed as a lightweight personal productivity tool. It provides a text-based interface for managing day-to-day tasks, tracking progress, and reviewing task statistics without needing a graphical interface or external database.

At startup, the app populates a few sample tasks so the user can immediately explore the features and test the workflow.

## Features

- Add new tasks with title, subject, optional description, and priority
- View all tasks or sorted tasks by priority
- Edit task details
- Delete tasks
- Increase or decrease priority levels
- Mark tasks as completed
- Search tasks by title, subject, priority, or description
- View summary statistics for tasks and subjects
- Stream task activity updates through a simple log-based event output
- Console-based interactive menu

## Tech Stack

- Dart
- Standard input/output from `dart:io`
- Object-oriented design with model and manager classes

## Core Components

### `main.dart`
The application entry point. It initializes the tracker, loads sample tasks, and runs the interactive loop that displays the main menu and handles user choices.

### `TaskTracker.dart`
This file contains the main logic for:
- adding tasks
- editing and deleting tasks
- sorting and viewing tasks
- changing task priority
- marking tasks complete
- searching tasks
- generating summary statistics
- streaming update logs

### `Task.dart`
Represents the `Task` model with these fields:
- `title`
- `subject`
- `priority`
- `description`
- `isCompleted`

### `TaskPriority.dart`
Defines the enum for task priority levels:
- `low`
- `medium`
- `high`

### `InputHandler.dart`
Provides a reusable input function that validates user input before continuing. It prevents empty or invalid responses and keeps the console app user-friendly.

## How to Run

Make sure Dart is installed on your machine.

From the project folder, run:

```bash
dart run main.dart
```

You can also run it directly with:

```bash
dart main.dart
```

## Menu Options

When the app starts, it displays a main menu:

```text
0. Exit
1. Add Task
2. View Tasks
3. Modify a Task
4. Search Tasks
5. Statistics
6. Watch Task Updates
```

### Option Details

1. Add Task
   - Enter a title and subject
   - Optional description
   - New task is added to the tracker

2. View Tasks
   - Displays all tasks in a readable format
   - Incomplete tasks are listed before completed tasks

3. Modify a Task
   - Select a task
   - Edit title, subject, or description
   - Delete it
   - Change its priority
   - Mark it complete

4. Search Tasks
   - Search by phrase matching title, subject, description, or priority

5. Statistics
   - Shows total tasks
   - Count of completed and incomplete tasks
   - Number of tasks per subject
   - High-priority unfinished tasks

6. Watch Task Updates
   - Streams the task log line by line with a one-second delay between entries

## Notes on the Implementation

This application follows a simple model-driven architecture:

- The `Task` model stores the actual task data.
- The `TaskTracker` class manages operations and state.
- The `main.dart` file orchestrates user interaction.
- Validation is handled centrally through `getUserInput`.

The project is intentionally compact and educational, making it a useful example of console app design in Dart.
